PRUEBAS AUTOMATIZADAS DEL CURSO JAVA

Responsable: Diego Rances Rojas Huaranga

OBJETIVO
Comprobar que los ejemplos del curso compilen
y produzcan los resultados esperados.

HERRAMIENTAS
Java 21
Bash
GitHub Actions

EJECUCION
bash scripts/test-java-examples.sh

COBERTURA

Leccion 01
- Mostrar correctamente los mensajes de bienvenida.

Leccion 02
- Comprobar String, int y double.
- Comprobar operaciones aritmeticas.

Leccion 03
- Comprobar las condiciones if.
- Comprobar los bucles for y while.

Leccion 04
- Comprobar la entrada de datos con Scanner.
- Comprobar la ejecucion de metodos.

Leccion 05
- Comprobar la creacion de objetos.
- Comprobar los constructores y metodos.

Leccion 06
- Comprobar getters y setters.
- Rechazar notas fuera del rango permitido.

Leccion 07
- Recorrer un arreglo de estudiantes.
- Calcular correctamente el promedio.

Leccion 08
- Registrar estudiantes.
- Mostrar estudiantes registrados.
- Buscar estudiantes por nombre.
- Calcular el promedio.
- Rechazar entradas no numericas.
- Rechazar nombres vacios.
- Rechazar notas invalidas.
- Comprobar el limite de diez estudiantes.
- Gestionar busquedas sin resultados.

VERIFICACION AUTOMATICA
Las pruebas se ejecutan mediante GitHub Actions
en los eventos configurados en el workflow.

ALCANCE
Se comprueban los ejemplos Java del repositorio.
Las pruebas no sustituyen la revision de videos,
audio, subtitulos ni las practicas en el navegador.
