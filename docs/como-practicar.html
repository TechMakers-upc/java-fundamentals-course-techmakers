Cómo realizar las prácticas

El curso está pensado para personas que nunca han programado. Todos los ejercicios funcionan desde un navegador, sin instalar Java.

1. Mira la videolección

Abre el video de la clase y sigue el ejemplo. Si algo pasa demasiado rápido, pausa y repite ese fragmento.

2. Abre el ejercicio

Desde la página principal selecciona Abrir práctica. Se mostrará un editor Java integrado con el código inicial del reto.

3. Modifica el código

Busca los comentarios que comienzan con RETO. Allí se explica qué parte debes completar o cambiar. Es normal equivocarse: el editor muestra mensajes que ayudan a identificar errores.

4. Ejecuta y comprueba

Pulsa Run dentro del editor. Lee el resultado y prueba otros valores. Cuando termines, compara tu propuesta con la carpeta completed-examples de GitHub.

5. Continúa con la siguiente lección

Las clases están ordenadas por dificultad. Te resultará más fácil el proyecto final si primero practicas las siete anteriores.

Preguntas frecuentes

¿Necesito instalar Java?

No. El editor se ejecuta en el navegador, mediante OneCompiler.

¿Qué pasa si el código no aparece?

Espera a que termine de cargar el editor y pulsa Cargar de nuevo el código inicial. Si el editor externo no carga, abre OneCompiler y copia el código desde la carpeta starter-files.

¿Qué hago si necesito ingresar datos?

Lee las indicaciones del ejercicio; algunos programas usan Scanner. Introduce los datos de ejemplo en el área de entrada del editor cuando corresponda.

¿Dónde encuentro una solución?

La solución completa está en completed-examples. Intenta resolver primero el reto por tu cuenta.

¿El proyecto final ya viene terminado?

No. El archivo inicial de la lección 8 contiene tareas para completar. El resultado terminado puede consultarse en la solución del repositorio.
