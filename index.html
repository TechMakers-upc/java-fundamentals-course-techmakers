Curso introductorio · 8 lecciones · ~59 minutos

Aprende Java desde cero, paso a paso

Si nunca has programado, este curso es para ti. Practicarás variables, condiciones, métodos y objetos hasta construir un pequeño registro de estudiantes.

Comenzar con la lección 1 Leer la guía de prácticas

Solo necesitas un navegador y conexión a Internet. No hay que instalar Java.

¿Cómo se aprende aquí?

  1. Observa: mira la videolección y presta atención al ejemplo.
  2. Practica: abre el ejercicio precargado, modifica el código y pulsa Run.
  3. Comprueba: compara el resultado con la solución del repositorio.
